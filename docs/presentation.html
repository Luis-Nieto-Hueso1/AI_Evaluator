Compatibility Scoring Engine

// Composite 0-100 score
score = speedScore x 0.55 + memScore x 0.35 + qualityBonus x 0.10

// Token speed estimation
GPU: tok/s = bandwidth(GB/s) x 0.70 / bytesPerToken
CPU: tok/s = bandwidth(GB/s) x 0.12 / bytesPerToken

// Grade mapping
85+ S | 70+ A | 55+ B | 40+ C | 20+ D | <20 F

Scoring inspired by canirun.ai with added quantization-aware speed estimation and memory bandwidth modeling.

Data Flow — Compatibility Check

Hardware FormRAM, GPU, CPU
→
Scoring Enginecompatibility.ts
→
CompatibleModel[]Graded S-F
Step What Happens
1. Variant Selection Pick highest-quality quantization that fits in available memory
2. Execution Mode GPU if VRAM sufficient, otherwise CPU (with RAM bandwidth)
3. Speed Estimation bandwidth x efficiency / bytesPerToken = tok/s
4. Score Computation 55% speed + 35% memory headroom + 10% model quality
5. Grade Assignment S (85+), A (70+), B (55+), C (40+), D (20+), F (<20)

Live Model Feed

  • Auto-fetches trending models from HuggingFace Hub + Ollama library on every page load
  • 24h localStorage cache — stale cache refreshed in background, fresh data shown immediately
  • Deduplication — fuzzy match on org + parameter count avoids duplicating static DB entries
  • Custom import — paste any HF URL to import a model with auto-estimated RAM/VRAM variants
  • Unified pipeline — live + custom + static models all flow through the same scoring engine
