Executive Summary

AI Evaluator is an interactive web application that helps developers, data scientists, and technical decision-makers determine which AI/ML models can run on their specific hardware, with instant compatibility grades, performance estimates, and deployment guidance.

The Problem

  • 50+ LLMs released annually with inconsistent documentation
  • No standardized way to match hardware to models
  • Teams waste weeks testing incompatible models
  • Deployment failures cost $10K–$100K in lost engineering time

The Solution

  • Instant hardware-to-model matching (<2 seconds)
  • Letter grades (S–F) for non-technical stakeholders
  • Performance predictions (tokens/sec, latency)
  • AI-powered recommendations via Claude API
  • Guided discovery flows for ML setup

Overview

What AI Evaluator Does

  • Analyzes your hardware (RAM, GPU, CPU, bandwidth)
  • Searches 50+ AI models from Hugging Face and Ollama
  • Calculates which models fit and how fast they run
  • Assigns letter grades (S=excellent, F=won't fit)
  • Shows performance estimates (tokens/second)
  • Provides deployment guidance with cost estimates

Core Features

1. Hardware Compatibility Engine

Enter your hardware specs (RAM, GPU, CPU) and instantly see which models you can run.

Key Metrics:
  • Memory utilization (% of available VRAM/RAM)
  • Tokens per second (inference speed)
  • Letter grade (S–F composite score)
  • Fit status (does model fit or not?)

2. AI Use-Case Advisor

Chat with Claude AI to get personalized model recommendations for your specific task.

Example:
User: "I need a model for code review on MacBook M3 with 36GB"
AI: "Qwen2.5 Coder 14B is S-tier for your setup. Deploy via Ollama in 10 minutes."

3. Model Leaderboard & Tier List

Browse all 50+ models ranked by benchmarks, performance, or your hardware grade.

  • Leaderboard: Sortable table with MMLU, HumanEval, MT-Bench scores
  • Tier List: Visual S–F ranking for your hardware
  • Download Links: Direct access to model downloads

4. Model Comparison

Compare any 2 models side-by-side: specs, benchmarks, use cases, costs.

5. Guided Discovery Flow (NEW)

A 3-step wizard that guides you through:

  • Step 1: Pick an ML algorithm (K-Means, Random Forest, Transformer, etc.)
  • Step 2: Get framework recommendations (PyTorch, TensorFlow, scikit-learn)
  • Step 3: See personalized summary with getting-started guide

6. Deployment Guide

Get step-by-step deployment guidance for your target environment.

  • Recommended inference stacks (Ollama, vLLM, TensorRT-LLM)
  • Installation commands
  • Configuration for your hardware
  • Cost and performance estimates

How It Works

Step-by-Step User Flow

1. Enter Your Hardware

  • Select GPU model (or input VRAM)
  • Enter RAM size
  • Choose CPU (optional)

2. Get Instant Results

  • App calculates compatibility for all models
  • Shows letter grades (S–F)
  • Displays speed estimates (tokens/sec)
  • Lists 50+ compatible models

3. Explore & Filter

  • Filter by grade (S, A, B, C, D, F)
  • Filter by use case (coding, summarization, etc.)
  • Sort by speed, parameters, context length
  • Compare any 2 models

4. Get Recommendations

  • Ask the AI advisor for your use case
  • Get deployment guide with install commands
  • Export results as CSV or JSON
  • Share hardware config via URL

Architecture & Technology

Technology Stack

Frontend

  • React 19.2.4 – Component-based UI with hooks
  • TypeScript 5.9 – Type-safe development
  • Tailwind CSS 4.2 – Utility-first responsive styling
  • Vite 8 – Lightning-fast dev server & builds

APIs & Integrations

  • Anthropic Claude API – AI advisor (optional)
  • Hugging Face Hub API – Live model feed
  • Ollama Registry API – Alternative models

Data Storage

  • localStorage – Client-side caching (24h models)
  • JSON files – Static data (50+ models, algorithms, frameworks)
  • URL params – Shareable hardware configs

Limitations

Current Version Scope

1. Hardware Coverage

Covers ~30 popular GPUs/CPUs. For unsupported hardware, manually enter VRAM + bandwidth.

2. Model Coverage

50+ open-source models included. Proprietary models (GPT-4, Claude) not covered. Requires 24h sync with Hugging Face.

3. Performance Estimation

Shows peak performance, not accounting for batching, system load, or quantization overhead. Use Benchmark Calibrator for personal accuracy.

4. Mobile Experience

Responsive but optimized for desktop. Model comparison and flowcharts may feel cramped on mobile.

5. Framework Selection

Covers 9 mainstream frameworks. Scoring is heuristic-based, not machine-learned.

6. Data Updates

24-hour cache means users might miss latest models released recently. Manual refresh available.

Getting Started

Using AI Evaluator

1. Visit the App

Go to: https://ai-evaluator.vercel.app

2. Enter Your Hardware

Use the Hardware Form on the left to input your setup (GPU, RAM, CPU).

3. Browse Results

See compatible models graded S–F, sorted by score.

4. Use the Tools

  • Results Tab: Browse & filter models
  • Guided Discovery: Step-by-step ML setup
  • AI Advisor: Chat for recommendations
  • Deployment Guide: See how to deploy
  • Leaderboard: Compare benchmarks

Tips & Tricks

  • Use "/" to focus search quickly
  • Click "Share" to send hardware config to teammates
  • Export as CSV/JSON for reports
  • Run "Benchmark Calibrator" for personal speed estimates
  • Dark mode toggle in top-right corner
